# 變更紀錄

## arcane-workbench-v2.0.0

將半套新版與根目錄舊版收斂成單一 local-first 產品：

- 首頁、調製台、胖譜庫、人物設定庫、材料庫與設定全部改用同一套頂部導覽與暗色魔導工作台視覺。
- 移除新版導覽對根目錄 API 工作台的連結；統一版不再讀寫 API key 或呼叫遠端生成服務。
- 將原本 `app.js` 加四層 enhancement 覆寫的執行鏈收斂到單一 `arcane-workbench.js`。
- 新增胖譜、人物與材料的完整新增、瀏覽、搜尋、篩選、編輯、刪除與套用流程。
- 人物固定配件維持獨立勾選；比例覆寫時只移除未鎖定的舊比例。
- 新增胖譜版本保存、完整 JSON 匯出／匯入與資料大小顯示。
- 新增舊配方引擎與舊正式版資料的去重遷移，不修改原 storage。
- 新增桌面／平板／手機響應式版面與手機底部導覽。
- 修正空白調製台貼入內容後，「拆成材料」按鈕仍保持停用的問題。
- 統一所有內頁為英文主標、中文功能副標；桌面導覽同步恢復英文優先的雙語層級。
- 衝突檢查保留為背景能力，不再以「規則庫」或材料規則等近似概念出現在使用者介面。

## recipe-engine-v1.2.0

蕎依壓力測試後的細節修正：

- 混合句若同時包含人物、持物、背景與視角描述，改由明確的動作／場景／構圖訊號優先接管，不再因代名詞或配件詞一律落入「人物」。
- 新增 `holds`、`cup`、`straw`、`juice`、`sky`、`low-angle`、`wide-angle`、`perspective` 等常見壓測詞。
- 點選材料區後方分類標籤後，保留水平捲動位置，避免視角自動跳回第一個分類。

## recipe-engine-v1.1.0

第一次實測後的邏輯修正：

- 配件管理欄位與最終胖譜輸出分離，不再用「名稱 + on + 位置」硬拼句子。
- 支援直接輸入中文配件描述，例如「戒指在左手中指、食指」。
- 常見中文配件與身體位置會轉成自然英文，例如 `rings on the left middle and index fingers`。
- 無法可靠翻譯時完整保留中文，不產生中英混接的機械句。
- 移除最終輸出中的 `selected accessories:` 介面標籤。
- 分類合併為較易理解的大類：人物、服裝配件、動作、場景、構圖鏡頭、光線色調、風格品質、尺寸、限制。
- `8K`、`ultra detail`、`premium lifestyle photography` 等連續品質材料會合併為同一張「風格／品質」卡。
- 材料區上方新增分類標籤與數量，可快速切換並縮短尋找距離。

## recipe-engine-v1.0.0

第一個可操作垂直切片：

- 新增完全獨立的配方引擎實驗目錄。
- 新增獨立 localStorage，避免影響正式版與舊實驗版。
- 新增 PromptFragment 拆解、分類、鎖定、停用、編輯、排序與恢復原文。
- 新增人物 [AA]/[BB] 替換、點綴材料、尺寸設定。
- 新增原順序／標準順序輸出。
- 新增不刪詞原則與未分類材料完整保留。
- 新增外部 JSON 衝突規則包，僅提醒、不自動刪除。
- 新增修改摘要與一鍵複製。
