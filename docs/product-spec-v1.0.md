# 胖譜小精靈 Product Spec v1.0

## 產品定位

胖譜小精靈是一個 local-first 的 AI 捏圖詞條調製台。

它不是單純的 prompt 取代工具，而是協助使用者解析、置換、保留、提醒、建議，並管理自己的人物設定、材料片段與胖譜收藏。

核心目標：

- 讓使用者貼上一段胖譜後，可以快速置換人物與風格。
- 支援部分保留、部分改寫，保留使用者控制權。
- 人物設定、胖譜庫、圖片與版本紀錄預設只存在使用者裝置。
- 新手能快速開始，熟手能逐步展開進階規則。

## 產品語氣與視覺

品牌語氣是「日系資料整理型小精靈」：

- 溫柔、可靠、精緻、有一點小自信。
- 功能名稱可以可愛，但狀態與隱私提醒要清楚。
- 避免太長、太吵、太像企業後台。

暫定文案：

- 空調製台：餵我胖譜，交給小精靈。
- AI 幫我挑：小精靈救救我。
- 解析 prompt：拆解胖譜。
- 生成 prompt：生成新胖譜。
- 儲存 prompt：收進胖譜庫。
- 可見度檢查：露出檢查。
- 衝突提醒：可能打架。

視覺方向：

- 魔導科技調製工坊，精緻、克制、資料整理感。
- 主色：深藏藍、霧面玻璃。
- 輔色：Arcane Cyan、Moonlit Violet、Champagne Gold。
- 提醒色：琥珀；高風險：紅；完成：綠。
- 背景使用低亮度深色；輸入框維持清楚的深色層級。
- Beam 只標示主操作或目前焦點，不作為通用裝飾。
- 第一版可先使用簡化 avatar 或占位圖。
- 正式小精靈主視覺之後由使用者生成後替換，UI 需保留可換圖資產位置。

## 第一版資訊架構

```text
胖譜小精靈
├─ WORKSPACE／調製台
├─ PROMPT LIBRARY／胖譜庫
├─ CHARACTER LIBRARY／人物設定庫
├─ MATERIAL LIBRARY／材料庫
└─ 設定
```

## 入口與導航

第一版打開 app 先進首頁，主要 Beam 入口為 `Open Workspace／開啟調製台`。

空狀態：

```text
餵我胖譜，交給小精靈。
```

初次使用引導：

- 在調製台空狀態顯示輕量引導卡。
- 標題：第一次來？
- 內容只放 3 步：貼上胖譜、選角色或建立人物設定、生成新胖譜。
- 按鈕：開始拆胖譜、看 1 分鐘教學。
- 教學用 modal 或側邊抽屜，不離開調製台。

全站導航：

- 桌機與手機都只保留同一套頂部導覽。
- 導航項目：WORKSPACE、PROMPT LIBRARY、CHARACTER LIBRARY、MATERIAL LIBRARY、SETTINGS。
- 右側固定標示 `LOCAL ONLY`，不顯示 API 或模型狀態。

## 調製台

核心流程：

```text
貼胖譜
→ 選角色
→ 選要改什麼
→ 拆解胖譜
→ 看小提醒
→ 生成新胖譜
→ 複製或收進胖譜庫
```

桌面版使用三欄布局：

```text
左欄：餵胖譜
中欄：怎麼改
右欄：小提醒 / 輸出
```

左欄內容：

- 原始胖譜輸入框。
- 原文連結。
- 輸出格式：自然語句 Prompt。
- 示範圖或封面圖，可選。
- 拆解胖譜。

中欄內容：

- 模式：重新施法、只動這幾格、系列模式。
- 選角色。
- 改寫項目。
- 咒語套用。
- 生成新胖譜。

右欄內容：

- 小提醒。
- 露出檢查。
- 可能打架。
- 最終胖譜。
- 修修胖譜。
- 版本紀錄。
- 複製胖譜 / 收進胖譜庫。

右欄 tabs：

```text
小提醒｜新胖譜｜修修胖譜｜版本
```

手機版暫定使用 stepper / accordion：

```text
餵胖譜 → 怎麼改 → 小提醒 → 新胖譜 → 修修胖譜
```

手機最短流程：

```text
貼胖譜 → 選角色 → 小精靈救救我 → 生成 → 複製
```

每個改寫項目支援：

- 原樣保留。
- 套用人物設定。
- 小精靈救救我。
- 我自己來。

## 調製台互動狀態

空白狀態：

- 顯示「餵我胖譜，交給小精靈。」
- 顯示大輸入框。
- 顯示初次使用引導卡。
- 拆解胖譜按鈕在貼上內容後啟用。

已貼上胖譜：

- 可先做本機初步判斷：比例、負面詞、角色代稱、單人/雙人/多人。
- 顯示拆解胖譜、收進胖譜庫。

拆解中：

- 顯示「小精靈正在拆胖譜...」。
- 可顯示人物、服裝、場景、風格、負面詞等進度項目。
- 不顯示假百分比。

已拆解：

- 顯示人物、服裝、場景、動作、風格、比例、負面詞。
- 啟用選角色、套咒語、生成新胖譜。

生成中：

- 顯示「小精靈正在重新施法...」。
- 鎖住主要設定，避免生成中途改內容。
- 允許取消。

已生成：

- 右欄切到新胖譜 tab。
- 顯示 preamble 短說明、final prompt、notes。
- 顯示複製胖譜、收進胖譜庫、修修胖譜。

修修胖譜：

- 使用者可上傳本機生成結果圖。
- 使用者輸入哪裡不對與想修改的方向。
- 基於上一版 prompt 產生下一版。
- 第一版圖片只作本機紀錄。

錯誤狀態：

- 錯誤訊息要人話，不顯示 raw error。
- 範例：規則包格式錯誤、備份檔案無法解析、本機空間不足。

## 人物設定

人物設定只存「角色本人」，不固定綁定 `[AA]`、`[BB]`。

調製台當次生成時依照人物順序自動分配：

- 第一位角色：`[AA]`
- 第二位角色：`[BB]`
- 第三位角色：`[CC]`

人物設定頁面：

- 角色總覽。
- 快速建立。
- 從舊胖譜匯入。
- 外觀重點。
- 固定標記與配件。
- 生成預覽。

人物設定總覽每張卡顯示：

- 大頭貼。
- 名稱。
- 外觀摘要。
- 最近使用。
- 固定標記/配件數量。
- 寫進胖譜習慣：少寫一點、照我填的寫、這次再問我。

新增角色入口：

- 自己填。
- 丟舊胖譜給小精靈。

快速建立欄位：

- 角色名稱，必填。
- 大頭貼，可跳過，只作 app 內顯示。
- 髮色。
- 髮型或髮長。
- 眼睛特徵。
- 身高/體型。
- 妝容。
- 眼鏡或常態配戴。
- 固定標記與配件。
- 是否啟用臉部參考保護語。

寫進胖譜的習慣：

- 少寫一點：交給參考圖，避免和臉、髮色打架。
- 照我填的寫：把填好的外觀重點放進胖譜。
- 這次再問我：每次生成前確認要不要寫。

從舊胖譜匯入流程：

```text
貼上舊胖譜
→ 小精靈拆出角色資訊
→ 顯示草稿
→ 使用者勾選要存入人物設定的項目
→ 建立角色
```

拆出的項目分組：

- 建議保存。
- 可能只是這張圖的設定。
- 不建議保存。

固定標記與配件只存基礎資料：

- 類型：刺青、痣、淚痣、疤、耳環、眼鏡、戒指、手錶、手鍊、項鍊、其他。
- 名稱。
- 位置。
- 左右側。
- 重要性：招牌、常規、可省略。

visible / partial / hidden 的具體寫法不放在人物設定，改由調製台依當次服裝、姿勢、場景與構圖產生並讓使用者確認。

角色預覽：

- 顯示「小精靈會這樣理解這個角色」。
- 用短摘要呈現，不輸出完整 prompt。

## 材料庫

材料庫存放常用 Prompt 片段，不存完整胖譜。

胖譜庫是完整 Prompt 收藏；材料庫是可套用的小片段。

分類：

- 臉部參考。
- 風格濾鏡。
- 光線。
- 人物質感。
- 負面詞。
- 禁止事項。
- 常用補強。
- 自訂分類。

材料卡顯示：

- 名稱。
- 分類。
- 短說明。
- 是否常用。
- 是否預設套用。

快速新增只需要：

- 名稱。
- 分類。
- 語句內容。

可選進階欄位：

- 中文說明。
- 適用情境。
- 預設套用。
- 可能衝突。

第一版內建少量預設材料：

- 臉部參考保護語。
- 寫實人物質感。
- 手部修正。
- 自然雙人互動。
- 避免文字 / logo / 水印。
- 復古底片正向宣告。
- 黑白電影感正向宣告。

調製台套用方式：

- 顯示「套用材料」。
- 預設只顯示常用 4-6 張。
- 其他用搜尋或展開。
- 操作：加入調製台、這次不用、收進材料庫。

第一版固定輸出自然語句 Prompt，不提供遠端生成或參數化輸出。

## 胖譜庫

胖譜庫存完整 prompt 與使用紀錄。

胖譜庫首頁顯示胖譜卡列表。

每張卡顯示：

- 封面圖。
- 標題。
- 標籤。
- 狀態：未捏、已捏、想重捏。
- 版本數。
- 最近使用時間。
- 版本數。
- 星號。

卡片操作：

- 打開。
- 拿去調製台。
- 改狀態。
- 星號。
- 更多。

篩選：

- 狀態：未捏、已捏、想重捏。
- 有封面 / 無封面。
- 單人 / 雙人 / 多人。
- 標籤。

排序：

- 最近新增。
- 最近使用。
- 版本最多。
- 星號優先。

新增胖譜入口：

- 新增胖譜。
- 從調製台收進胖譜庫。

新增欄位：

- 標題。
- 原始胖譜。
- 原文連結。
- 封面圖，可選。
- 示範圖，可選。
- 狀態，預設未捏。
- 標籤。
- 備註。

小精靈可建議標籤：

- 單人 / 雙人 / 多人。
- 情侶。
- 日系。
- 海邊。
- 室內。
- 寫實。
- 需要參考圖。
- 有指定服裝。
- 有指定背景。

胖譜詳情頁顯示：

- 封面圖 / 示範圖。
- 標題。
- 原文連結。
- 原始胖譜。
- 標籤。
- 備註。
- 版本紀錄。

版本紀錄每版顯示：

- 版本名稱：V1 / V2 / V3。
- prompt。
- 結果圖，可選。
- 使用角色。
- 套用材料。
- 回饋備註。
- 滿意度：喜歡 / 普通 / 不行。
- 生成日期。

圖片用途：

- 胖譜封面。
- 示範圖。
- 生成結果圖。
- 版本紀錄縮圖。

第一版圖片只本機保存，不自動分析或上傳。

Threads 連結第一版只紀錄連結，不自動抓內容。

## 設定與隱私

預設 local-first。

使用者資料：

- 人物設定、胖譜庫、圖片、版本紀錄預設只存在本機。
- 圖片只作 app 內顯示，不自動上傳。
- 不保存 API key，也不提供遠端生成流程。

設定頁分區：

- 本機資料。
- 匯入與匯出。
- 規則包。
- 清除資料。

編譯說明：

- 固定使用本機模式。
- 拆解、分類、置換與重組只依本機規則執行。
- 不提供 API、模型選擇、遠端生成或失敗後降級流程。

本機資料第一版支援：

- 匯出備份。
- 匯入備份。
- 查看資料大小。
- 清除快取。
- 刪除全部資料。

備份第一版先支援 JSON 匯出 / 匯入。加密備份第二階段。

預設輸出設定：

- 預設輸出順序：原順序 / 標準配方順序。
- 預設是否加臉部參考保護語。
- 預設模式：重新施法 / 只動這幾格。
- 預設寫進胖譜習慣：少寫一點 / 照我填的寫 / 這次再問我。
- 預設輸出：中文說明 + 英文胖譜 / 只輸出英文胖譜。

## 主要元件樣式

按鈕：

- 主操作按鈕用實心色，例如拆解胖譜、生成新胖譜。
- 次要操作用描邊或淡底，例如收進胖譜庫。
- 危險操作用紅色，只用在刪除、清空資料。
- 按鈕文字短，不塞長句。
- 可搭配 icon，例如複製、儲存、上傳、設定。

卡片：

- 用在人物設定、胖譜卡、材料卡、提醒卡。
- 圓角約 8px。
- 不要卡片包卡片。
- 資訊要能掃讀：標題、標籤、狀態、最近使用。

標籤：

- 用於分類：日系、情侶、海邊、已捏、未捏。
- 顏色要克制。
- 狀態標籤固定色：已捏為綠，未捏為灰，想重捏為琥珀。

提示 / 小提醒：

- 普通提醒：淡藍或淺灰。
- 需要注意：琥珀。
- 高風險：紅。
- 提醒文字要短，展開後才顯示詳細原因。

輸入框：

- 胖譜輸入框要大、舒服。
- 支援貼長文。
- 有字數或大約 token 提醒。
- 長 prompt 輸出區要有複製、收合、全螢幕查看。

選項：

- 二選一用 toggle。
- 多選用 checkbox 或 selectable chip。
- 模式選擇用 segmented control。
- 原樣保留 / 套用人物設定 / 小精靈救救我 / 我自己來，用四段 segmented control。

## 第一版 MVP

應做：

- Responsive PWA 介面。
- 本機資料儲存。
- 調製台主流程。
- 人物設定建立與管理。
- 從舊胖譜匯入角色草稿。
- 材料庫。
- 胖譜庫基本收藏。
- 規則包匯入與恢復。
- 修修胖譜輕量版。
- 版本紀錄。

暫緩：

- 自動抓 Threads 內容。
- 自動分析圖片。
- 自動上傳圖片到 AI。
- 多裝置同步。
- 社群分享。
- 金流/會員。
- 後端代管 API。
- 使用者帳號系統。
- Midjourney 或參數化輸出。

## 重要產品原則

- 先能用，再變強。
- 必要時才問。
- 新手看得到功能存在，但不需要一開始填完。
- 人物設定庫存人，材料庫存片段，胖譜庫存完整 Prompt，調製台處理當次操作。
- 使用者明確指定優先於小精靈判斷。
- 避免過度描述臉部五官，臉部身份交給參考圖與 face reference 保護語。
- 第一版固定使用本機確定性編譯與自然語句輸出。
